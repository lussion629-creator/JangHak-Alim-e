# 장학알리미

대학생이 지원할 수 있는 장학금을 한곳에서 찾고, 마감을 놓치지 않게 도와주는 웹앱입니다.

웹앱: https://lussion629-creator.github.io/JangHak-Alim-e/

## 기능

- **장학금 찾기** — 지원 종류(등록금·생활비·기숙사·학자금 대출·근로 등), 모집 상태, 지역, 운영 기관으로 고르고, 장학금명·재단·지역·학교·학과로 검색
- **내 정보 맞춤** — 학교·학과·지역·소득구간 등을 넣으면 지원 가능 / 확인 필요 / 지원 불가와 그 이유를 보여 줌. 스위치로 켜고 끌 수 있고, 언제든 초기화
- **학교별 보기** — 한양대·한양여대·강원대 삼척·서강대·건국대 학생이 지원할 수 있는 장학과 학교 전용 장학을 따로 볼 수 있음
- **새 장학 표시** — 새로 올라오거나 바뀐 장학을 색깔로 구분
- **숨기기** — 관심 없는 장학을 목록·달력에서 빼고, 필요하면 다시 보기
- **마감 달력** — 날짜별 마감·접수 시작, 작년 일정으로 올해 모집 예상
- **관심 장학** — 별표로 모아 보고, 마감일을 휴대폰 캘린더에 넣기
- **서류 쓰기** — 추천서 부탁 메일·추천서·자기소개서 초안을 만들 수 있는 AI용 글 만들기
- **다크 모드**, 휴대폰 홈 화면에 추가해 앱처럼 쓰기, 인터넷이 없어도 마지막 목록 보기

## 개인정보

입력한 내 정보·관심 장학·숨긴 장학은 각자의 휴대폰(브라우저)에만 저장되고 서버로 보내지 않습니다.
