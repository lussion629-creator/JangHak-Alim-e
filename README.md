# 장학알리미 (전국판)

한국장학재단 공공데이터, 한양대 HY-in 장학캘린더, 한양대 공지, 대학·재단·지자체 장학 게시판을 한 DB로 모으는 앱입니다. 수집은 서버가 주기적으로 자동으로 다시 합니다. 화면은 웹앱(PWA)이라 휴대폰에서 "홈 화면에 추가"하면 앱처럼 쓸 수 있습니다.

## 화면 기능

- 검색, 모집 상태·대상·지역·운영기관·유형·출처 필터, 마감 임박/지원금/최근 등록/다음 모집 예상 정렬
- **내 조건**: 학교 유형, 학기, 계열, 학자금 지원구간, 평점, 본인·부모 주소지, 다자녀·장애·다문화 등 → 장학금마다 **지원 가능(초록) / 확인 필요(노랑) / 지원 불가(빨강)**와 판단 근거
- 마감 달력(작년 일정 기반 올해 예상 포함), 관심 등록, 구글 캘린더 추가, ICS 달력 구독(`/api/calendar.ics`)
- 출처·갱신 화면: 출처별 수집 결과, 새로 들어오거나 바뀐 장학금, 수집 대상 기관 551곳 목록

## 자동 갱신 서버를 켜는 세 가지 방법

**1) 내 PC에서 (가장 간단)** — `START-Windows.cmd` 더블클릭. Python 3.11+ 필요. http://localhost:8000 이 열리고, 서버가 켜져 있는 동안 6시간마다 다시 수집합니다.

**2) 무료 클라우드에 상시 운영 (추천: GitHub)** — 이 폴더를 GitHub 저장소로 올리고 Settings → Pages → Source를 **GitHub Actions**로 바꾸면 `.github/workflows/refresh.yml`이 6시간마다 수집 → 데이터 커밋 → `https://<아이디>.github.io/<저장소>/`에 배포합니다. PC를 꺼도 계속 최신입니다. 정부24 API 키는 Settings → Secrets → `GOV24_API_KEY`.

**3) Docker 서버** (Render, Fly.io, 학교/개인 서버) — `docker build -t jangak . && docker run -p 8000:8000 -e ADMIN_TOKEN=비밀값 jangak`

## HY-in(한양 포털) 장학캘린더 갱신

포털은 로그인이 필요해서 서버는 비밀번호를 받지 않습니다. 포털에 로그인 → 장학캘린더 화면 → F12 콘솔에 `web/tools/hyin-sync.js` 내용을 붙여 넣으면 전체 캘린더와 모집공지 상세를 모아 서버(`SERVER`, `TOKEN` 입력 시)로 올리거나 JSON 파일로 저장합니다. 파일은 `data/imports/`에 넣으면 다음 갱신 때 반영됩니다. HY-in 내용은 학내 공개 자료이므로 앱을 외부에 공개할 때는 이 출처를 끄는 것이 안전합니다(`server/refresh.py`의 `COLLECTORS`에서 `hyin` 제거).

## 수집 기관 추가

`data/registry/sources.json`에 `{"id","name","type","region","notice_url","rss","enabled":true}`를 넣으면 다음 갱신부터 수집합니다. K2Web(`/bbs/{site}/{id}/artclList.do`) 게시판은 RSS(`rssList.do`)를 자동으로 시도합니다. robots.txt가 막은 곳은 수집하지 않습니다. 드림스폰·링커리어 같은 모음 사이트는 이용약관상 복제가 제한되어 링크만 둡니다.

## 확인한 것과 남은 것

- 확인: 오프라인 사본으로 전체 갱신 → DB → JSON 내보내기, API(목록·상세·메타·ICS·인증), 웹 화면(데스크톱·휴대폰, 라이트·다크).
- 아직 실제로 돌려 보지 못한 것: 기관 게시판 551곳 온라인 수집. 작업 환경의 인터넷이 막혀 있어 첫 실행은 GitHub Actions나 PC 서버에서 이뤄집니다. 첫 실행 뒤 출처·갱신 화면에서 기관별 성공/실패를 확인하고, 실패한 곳은 `notice_url`을 고치면 됩니다. 기관 목록 중 주소가 검증된 곳은 대학 58, 재단 31, 지자체 14곳이고 나머지는 "주소 확인 필요"로 표시됩니다.
- 자동 판정은 공고 문장을 규칙으로 읽은 결과입니다. 최종 기준은 항상 공고 원문입니다.

## 안드로이드 앱(APK)

`jangak-alimi-1.0.0.apk` — 패키지 `kr.jangak.alimi`, Android 7.0 이상. 웹앱과 장학금 DB 사본이 앱 안에 들어 있어 오프라인에서도 열립니다. ‘출처·갱신’ 화면에 자동 갱신 서버 주소(GitHub Pages 등)를 넣으면 앱을 열 때마다 서버의 최신 DB를 받아 옵니다. 관심 등록한 장학금이 3일 안에 마감되면 앱을 열 때 알림을 띄웁니다.

다시 빌드: `android/tools/`에 aapt2, android.jar(API 35), d8.jar, apksigner.jar를 두고 `android/build.sh`. 업데이트 설치가 되려면 같은 `android/release.jks`로 서명해야 하니 이 파일을 잃어버리지 마세요.
